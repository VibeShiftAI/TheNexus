6. Step bursts and React's update limit
The browser check's long turn sends 520 tool calls 50 ms apart, 20 a second.
That is five times the busiest second in real sessions: the 400 newest Claude
Code transcripts on this machine on 2026-11-23 held 3,275 tool calls (38 of the
transcripts made any), with at most 4 started in one second.

At 100 calls a second the home page throws React's "Maximum update depth
exceeded", with or without this task. Each frame on the global event stream
commits synchronously through dashboard/src/lib/praxis-stream-store.ts, and the
live board's drain effect then schedules another update, so a page with 35
project cards falls behind the stream. This task does not change that store.
